通知渠道

来短信灯光

设备收到新短信时，RGB 氛围灯按此反馈（需设备在线且已烧录新固件）

关闭则来短信不触发灯光反馈

来电话灯光

设备有来电（含未接/拒接）时，RGB 氛围灯按此反馈

关闭则来电不触发灯光反馈

勾选后灯光交替闪烁，更醒目
